{{usage}}

Rolls back the MOST RECENTLY applied migration (one step). DESTRUCTIVE: refuses
to proceed unless the operator types confirm on stdin, or passes --confirm.

  --provider         Database dialect. Required.
  --connection       Connection string. Required (or set the per-dialect env var below).
  --migrations-path  Full path to the migrations directory.
  --migrations-root  Root prefix; the script then looks at <migrations-root>/<dialect>/migrations.
                     Defaults to 'sql'. Ignored when --migrations-path is also set.
  --confirm          Skip the interactive prompt.

Examples:
  # sqlite — bare path or sqlite:// URL.
  {{command}} --provider sqlite --connection ./app.sqlite
  {{command}} --provider sqlite --connection sqlite:///absolute/path/app.sqlite

  # postgres — URL or keyword form.
  {{command}} --provider postgres --connection postgresql://user:pass@host:5432/dbname

  # mysql — URL form.
  {{command}} --provider mysql --connection mysql://user:pass@host:3306/dbname

  # sqlserver / oracle — pass a driver-native connection string.
  {{command}} --provider sqlserver --connection "Server=host;Database=dbname;User Id=user;Password=pass;"
  {{command}} --provider oracle   --connection "user/pass@host:1521/service"

  # env-var fallback when --connection is omitted:
  SQLITE_PATH=./app.sqlite       {{command}} --provider sqlite
  DATABASE_URL=postgresql://...  {{command}} --provider postgres

  # custom migrations layout (default looks under sql/<dialect>/migrations):
  {{command}} --provider sqlite --connection ./app.sqlite --migrations-path ./db/changes/sqlite

Per-dialect env vars consulted when --connection is omitted:
  sqlite     SQLITE_PATH, DB_PATH
  postgres   PG_CONNECTION_STRING, DATABASE_URL
  mysql      MYSQL_URL, DATABASE_URL
  sqlserver  MSSQL_URL, DATABASE_URL
  oracle     ORACLE_CONNECT_STRING, DATABASE_URL
