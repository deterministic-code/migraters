{{usage}}

Selects the programming language and dialects this tree will compile and
install. --language is required. Repeat --dialect once per provider.
Re-running replaces the previous language and dialect set. --all restores
every dialect. Does not take --connection.

  --language  Programming language runner to install and build. typescript, csharp, or rust.
  --dialect   Dialect to enable. Repeat for each dialect. Aliases from this file apply.
  --all       Enable every dialect. Restores the committed full-provider set.

Examples:
  {{command}} --language typescript --dialect sqlite --dialect postgres
  {{command}} --language csharp --dialect sqlite
  {{command}} --language rust --all
